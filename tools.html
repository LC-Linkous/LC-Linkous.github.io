Browser-based instruments for RF work and for teaching. Each one is a static page: open it, connect the hardware over USB, and work. Nothing to install for the serial devices, and every page has a Try without hardware button that runs it against a simulated device, so any of them can be tried right now.

Direct-USB tools need Chrome or Edge, the browsers that implement Web Serial. Firefox and Safari run the demo modes, and Firefox runs hackrf-web through its bridge.

How these are built

Each tool is its own repository with its own device layer. What they share is a convention: a PROTOCOL.md that the page, the simulated device, and (where there is one) the firmware are all written against. Where a tool has a Python library for the same hardware, the two mirror each other so a measurement can start in the browser and finish in a script. The Python libraries, the command-line tools, and the firmware are listed on Projects.

Anything that can transmit or drive an output starts in a safe state: hackrf-web's transmit is locked behind a bridge flag, the fox firmware ships receive-only, and the LED lab zeroes its outputs whenever it lets go of the board.

The measurement tools each have a Diagnostics section that downloads a JSON report of raw device replies, and fox-hunt-web can download its console log. Attached to a GitHub issue, either one helps validate the hardware listed as untested above.

Source is on GitHub under the GPL; licenses are in each repository.
