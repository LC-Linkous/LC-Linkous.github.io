Tools

Small browser-based bench tools. Each one is a static page: open it in Chrome or Edge, plug the hardware in over USB, and go. Nothing to install, and every tool has a try without hardware mode so it can be previewed anywhere. Source for each lives on GitHub under the GPL.

Radio & RF

nanoVNA Web · source
A browser front end for the NanoVNA-F V2 and F V3: S11/S21 traces, SWR, Smith chart, a live waterfall, markers with an R + jX readout, calibration, recording, and CSV / Touchstone export. Companion to the nanoVNA_python library.
fox-bench · source
A workbench for small amateur-radio fox transmitters built on a CircuitPython board and a NiceRF SA8x8 module. Configure the fox in a form, preview the Morse ID, song, SSTV picture or QRSS trace, then write the firmware to the board over USB and bench-test it.

How they fit together

The pages share a layout and a device layer: a USB serial link, a model table, and a simulated device that answers with the same bytes as the real one. Where there is a Python library for the same hardware, the page mirrors its command set, so files move between the two (.csv, .s1p, .json). Each tool has an About page describing what it supports, its known limits, and what is next.

Found a device that doesn't behave? Every page has a Diagnostics or Connect section that collects a sample to attach to a GitHub issue.
